# CineSenseAI Deployment Guide 🚀

This document outlines the deployment options for **CineSenseAI** to run live in the cloud.

---

## Architecture in Production

CineSenseAI is designed with a **unified production architecture**:
1. **Frontend**: Vite + React 18 + TypeScript builds static HTML, CSS, and JS into `frontend/dist/`.
2. **Backend**: FastAPI loads the MovieLens dataset, fits TF-IDF and Collaborative filtering matrices on startup, serves all REST endpoints (`/api/...`), and mounts `frontend/dist/` at root `/`.
3. **Single Port / Zero CORS**: A single container or service serves both the API and the web client on standard port `$PORT`.

---

## Option 1: 1-Click Deployment on Render (Recommended Free Tier)

Render supports Docker web services with automatic builds from your GitHub repository.

### Steps:
1. Push your repository to GitHub:
   ```bash
   git push origin main
   ```
2. Go to [https://dashboard.render.com/](https://dashboard.render.com/) and click **New + > Web Service**.
3. Connect your GitHub repository: `https://github.com/nivetha44/CineSenseAI`.
4. Render will detect the repository. Select:
   - **Environment**: `Docker`
   - **Dockerfile Path**: `./Dockerfile`
   - **Plan**: `Free`
   - **Health Check Path**: `/api/health`
5. Click **Create Web Service**.
6. Render will build the multi-stage Docker container (compiling React and installing Python dependencies) and start the service.
7. Your live URL will be:
   ```
   https://cinesense-ai.onrender.com
   ```
   *(Or the custom slug generated by Render)*

---

## Option 2: Deployment on Railway

1. Sign in to [Railway.app](https://railway.app/).
2. Click **New Project** → **Deploy from GitHub repo**.
3. Select `nivetha44/CineSenseAI`.
4. Railway will automatically detect the `Dockerfile` in the root directory.
5. In project settings, add the environment variable:
   - `PORT` = `8000`
6. Click **Generate Domain**. Railway will provide a live HTTPS URL.

---

## Option 3: Local Docker Container

You can run the production container locally with Docker:

```bash
# Build and run using Docker Compose
docker-compose up --build

# Open in browser:
http://localhost:8000
```

Or manually:
```bash
docker build -t cinesense-ai .
docker run -p 8000:8000 cinesense-ai
```

---

## Option 4: Split Deployment (Frontend on Vercel, Backend on Render)

If you prefer to host the static UI on Vercel:

1. **Deploy Backend on Render** (following Option 1).
2. Note your backend URL (e.g., `https://cinesense-backend.onrender.com`).
3. In `frontend/vercel.json`, update the proxy target to your backend URL:
   ```json
   {
     "rewrites": [
       {
         "source": "/api/(.*)",
         "destination": "https://cinesense-backend.onrender.com/api/$1"
       },
       {
         "source": "/(.*)",
         "destination": "/index.html"
       }
     ]
   }
   ```
4. Deploy the `frontend/` directory to Vercel via GitHub or `vercel deploy`.

## Verifying the Deployment

Once deployed, verify that the health check responds with `200 OK`:
```bash
curl https://<YOUR_DEPLOYED_URL>/api/health
```
Expected response:
```json
{
  "status": "healthy",
  "service": "CineSenseAI",
  "version": "1.0.0",
  "catalog_size": 9742,
  "engine_ready": true
}
```
Open `https://<YOUR_DEPLOYED_URL>/` in your browser to interact with the full web application!
